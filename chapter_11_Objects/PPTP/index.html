108 - Objects Basics

108_Objects.js Key-Value Pairs

Introduction to JavaScript objects using key-value pairs. Covers creating objects with literal syntax, accessing properties with dot notation and bracket notation, and understanding that objects are copied by reference (not by value).

let student1 = { name: "Amit", age: 65 };
let student3 = { name: "Pramod", age: 87, phone: 987654320 };

// Accessing properties
console.log(student3.name);       // dot notation
console.log(student3["phone"]);  // bracket notation

// Objects are copied by REFERENCE
let b = student1;
b.name = "Changed";
console.log(student1.name); // "Changed" — same object!

109 - Objects & Const

109_Objects_Consts.js Const Objects

Demonstrates how const works with objects. The variable binding is immutable, but the object's properties can still be modified. Also covers dynamic property access using a variable as a key.

const user = { name: "John", age: 30, email: "john@example.com" };

// Accessing properties
console.log(user.name);
console.log(user["age"]);

// Dynamic property access
const key = "age";
console.log(user[key]); // 30

110 - Dynamic Properties

110_Objects.js Add & Delete

Shows how to dynamically add new properties to an object, update existing ones, and delete properties using the delete operator. Useful for building config objects on the fly.

let config = {};
config.browser = "Chrome";
config.timeout = 3000;
config.timeout = 5000; // overwrite
console.log(config);

delete config.browser;
console.log(config); // { timeout: 5000 }

111 - Primitive vs Reference

111_Primitive_Ref.js Call by Value vs Ref

The critical difference between primitive types (copied by value) and objects (copied by reference). Primitives like numbers and strings create independent copies, while objects share the same memory address.

// Primitive — call by value
let a = 10;
let b = a;
b = 99;
console.log(a); // 10 — unchanged

// Objects — copied by REFERENCE
let obj1 = { status: "pass" };
let obj2 = obj1;
obj2.status = "fail";
console.log(obj1.status); // "fail" — same object!

113 - Method Chaining

113_Objects.js this & Chaining

Demonstrates method chaining by returning this from object methods. This pattern allows calling multiple methods in sequence on the same object — a pattern commonly seen in test frameworks.

const calculator = {
    value: 0,
    add(n) {
        this.value += n;
        return this;
    },
    substract(n) {
        this.value -= n;
        return this;
    }
};

calculator.add(10).substract(3).add(5);
console.log(calculator.value); // 12

114 - Object Destructuring

114_Object_Dec.js Destructuring

Unpacking object properties into variables using destructuring syntax. Covers basic destructuring, renaming variables, setting default values, and nested destructuring for deeply nested objects.

const user = { name1: "John", age: 30, city: "NYC" };

// Basic destructuring
const { name1, age } = user;

// Rename variables
const { name1: userName, age: userAge } = user;

// Default values
const { country = "USA" } = user;

// Nested destructuring
const data = { user: { address: { city: "NYC" } } };
const { user: { address: { city } } } = data;

115 - Spread & this

115_Spead_Objects.js Spread Operator

Using the spread operator (...) to copy and merge objects. Also introduces the this keyword inside object methods to reference the object's own properties.

const obj1 = { a: 1, b: 2 };
const obj2 = { c: 3, d: 4 };

const copy = { ...obj1 };
const merged = { ...obj1, ...obj2 };

// this keyword
const user = {
    name: "Pramod",
    saymyName(lastName) {
        this.name += lastName;
        return this.name;
    }
};

116 - Getter & Setter

116_GETTER_SETTER.js get / set

Defines computed properties using get and set accessors. The getter computes a value on read; the setter transforms input on write — useful for derived properties like full names.

const user = {
    firstName: "Pramod",
    lastName: "Dutta",
    get fullName() {
        return this.firstName + this.lastName;
    },
    set fullName(value) {
        [this.firstName, this.lastName] = value.split(" ");
    }
};

console.log(user.fullName); // PramodDutta
user.fullName = "Amit Sharma";
console.log(user.fullName); // AmitSharma

117 - Object Methods

117_Objects_methods.js keys / values / entries

Built-in methods for iterating over objects: Object.keys(), Object.values(), Object.entries(), and the for...in loop. Essential for inspecting and transforming object data.

const obj = { a: 1, b: 2, c: 3 };

console.log(Object.keys(obj));    // ["a", "b", "c"]
console.log(Object.values(obj));  // [1, 2, 3]
console.log(Object.entries(obj)); // [["a",1], ["b",2], ["c",3]]

for (const key in obj) {
    console.log(`${key}: ${obj[key]}`);
}

119 - let vs const Objects

119_Let_const_Objects.js Mutability

Key difference: let allows reassigning the entire object, while const only locks the binding — you can still modify properties. Both allow property changes, but only let allows full reassignment.

let config1 = { browser: "Chrome", timeout: 3000 };
config1 = { browser: "Safari" }; // ✅ allowed with let

const config = { browser: "Chrome", timeout: 3000 };
config.browser = "Firefox";  // ✅ modify property — allowed
config.retries = 2;          // ✅ add property — allowed
// config = {};              // ❌ reassign — TypeError!
