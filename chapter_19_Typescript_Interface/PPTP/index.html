Chapter 19: TypeScript Interface

Defining contracts with interfaces — object shapes, optional/readonly properties, method signatures, class implementation, and real QA patterns.

184 - Interface Basics

184_TS_Interface.ts Interface Shape

An interface defines the shape (structure) of an object. If your object doesn't match the interface, TypeScript throws a compile-time error — catching bugs before tests even run.

interface TestCase {
    id: number;
    name: string;
    status: string;
    duration: number;
}

let test1: TestCase = {
    id: 1,
    name: "Login with valid credentials",
    status: "PASS",
    duration: 1500
};

console.log("TC-" + test1.id + ": " + test1.name + " → " + test1.status);

185 - Optional & Readonly

185_TS_Interface2.ts ? and readonly

readonly properties can't be modified after creation. ? marks properties as optional — they can be omitted without error. Perfect for API response shapes.

interface APIResponse {
    readonly statusCode: number;
    body: string;
    headers?: object;      // optional
    responseTime?: number; // optional
}

let response: APIResponse = {
    statusCode: 200,
    body: '{\"user\": \"admin\"}',
};

// response.statusCode = 404; // ❌ Error: readonly!

186 - Method Signatures

186_TS_Method_Sign.ts Methods in Interface

Interfaces can define method signatures — any object implementing the interface must provide these methods with matching parameter and return types.

interface Calculator {
    add(a: number, b: number): number;
    subtract(a: number, b: number): number;
    multiply: (a: number, b: number) => number;
}

const calc: Calculator = {
    add: (a, b) => a + b,
    subtract: (a, b) => a - b,
    multiply: (a, b) => a * b,
};

187 - Function Interface (Hook)

187_TS_Interface_Hook.ts Callable Interface

An interface can define a function signature (callable type). Here TestHook ensures all hook functions accept a test name string and return void — like Playwright's beforeEach/afterEach.

interface TestHook {
    (testName: string): void;
}

let beforeEachHook: TestHook = function(testName: string): void {
    console.log("[BEFORE] Setting up: " + testName);
};

let afterEachHook: TestHook = function(testName: string): void {
    console.log("[AFTER] Tearing down: " + testName);
};

beforeEachHook("Login Test");

188 - Real Bug Report

188_TS_REAL_BUG_REPORT.ts Real QA Interface

A BugReport interface with typed fields for id, title, severity, and steps to reproduce (string array). Used with a logBug() function that formats the report.

interface BugReport {
    id: number;
    title: string;
    severity: string;
    stepsToReproduce: string[];
}

function logBug(bug: BugReport): void {
    console.log("BUG-" + bug.id + " [" + bug.severity + "] " + bug.title);
    bug.stepsToReproduce.forEach(function(step, i) {
        console.log("  " + (i+1) + ". " + step);
    });
}

189 - Real Test Config

189_TS_TestConfig_REAL.ts Config Interface

A TestConfig interface with required fields (browser, headless, baseURL) and optional fields (timeout, retries). Create different configs for CI vs local development.

interface TestConfig {
    browser: string;
    headless: boolean;
    baseURL: string;
    timeout?: number;
    retries?: number;
}

let ciConfig: TestConfig = {
    browser: "Chrome",
    headless: true,
    baseURL: "https://staging.app.com"
};

let localConfig: TestConfig = {
    browser: "Firefox",
    headless: false,
    baseURL: "http://localhost:3000",
    timeout: 60000,
    retries: 2
};

190 - Page Object Interface

190_REAL_PAGE_OBJECT_Interface.ts Interface Extends

Interfaces can extend other interfaces. LoginPage extends BasePage to inherit url/title and add login-specific selectors — building a typed Page Object Model.

interface BasePage {
    url: string;
    title: string;
}

interface LoginPage extends BasePage {
    usernameSelector: string;
    passwordSelector: string;
    loginButtonSelector: string;
}

interface FreeTrailPage extends BasePage {
    usernameSelector: string;
    submitButtonSelector: string;
}

191 - Class implements Interface

191_TS_Class_Interface.ts implements

A class can implement an interface — it must provide all properties and methods defined in the interface. TypeScript enforces this contract at compile time.

interface Executable {
    name: string;
    run(): void;
    getStatus(): string;
}

class TestCase implements Executable {
    name: string;
    constructor(name: string) {
        this.name = name;
    }
    run(): void {
        console.log("[RUN] " + this.name);
    }
    getStatus(): string {
        return "PASS";
    }
}

192 - Index Signatures

192_Index_TS_Sing.ts Dynamic Keys

Index signatures allow objects with dynamic keys. [key: string]: string means any string key mapping to a string value — useful for dictionaries, configs, and environment variables.

interface StringDictionary {
    [key: string]: string;
}

const dict: StringDictionary = {
    hello: "world",
    foo: "bar"
};

// Any string key works:
dict["newKey"] = "newValue"; // ✅
// dict["key"] = 123;         // ❌ must be string
