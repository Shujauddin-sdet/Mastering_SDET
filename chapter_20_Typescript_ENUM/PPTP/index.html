Named constants with enums — string enums, numeric enums, reverse mapping, and real QA patterns for browser selection and HTTP methods.

193 - String Enum Basics

193_ENUM.ts String Enum

Enums define a set of named constants. String enums map each member to a string value — readable, type-safe, and autocomplete-friendly in your IDE.

enum TestStatus {
    Pass = "PASS",
    Fail = "FAIL",
    Skip = "SKIP",
    Pending = "PENDING",
    Blocked = "BLOCKED"
}

console.log(TestStatus.Pass); // "PASS"
console.log(TestStatus.Fail); // "FAIL"

194 - Numeric Enum & Functions

194_ENUM_Fn.ts Numeric Enum

Numeric enums auto-increment from 0 (or a custom start). They support reverse mapping — you can get the name from the number. Use in functions for type-safe comparisons.

enum Severity {
    Low,      // 0
    Medium,   // 1
    High,     // 2
    Critical  // 3
}

function needsImmediateAttention(severity: Severity): boolean {
    return severity >= Severity.High;
}

console.log(needsImmediateAttention(Severity.Low));      // false
console.log(needsImmediateAttention(Severity.Critical)); // true
console.log(Severity[2]); // "High" — reverse mapping!

195 - Real Browser Selection

195_REAL_BRowser_Selection.ts Switch + Enum

Real SDET pattern: a Browser enum with a switch statement to launch the correct browser engine. Maps directly to Playwright's browser selection logic.

enum Browser {
    Chrome = "chrome",
    Firefox = "firefox",
    Safari = "safari",
    Edge = "edge"
}

function launchBrowser(browser: Browser): void {
    switch (browser) {
        case Browser.Chrome:
            console.log("Launching Chromium (Chrome v120)");
            break;
        case Browser.Firefox:
            console.log("Launching Gecko (Firefox v115)");
            break;
        case Browser.Safari:
            console.log("Launching WebKit (Safari v17)");
            break;
    }
}

launchBrowser(Browser.Chrome);

196 - Enum API Example

196_ENUM_API_example.ts HTTP Methods

An HTTPMethod enum for type-safe API calls. Prevents typos like "DLETE" — the enum restricts to valid values only.

enum HTTPMethod {
    GET = "GET",
    POST = "POST",
    PUT = "PUT",
    DELETE = "DELETE"
}

function sendRequest(method: HTTPMethod, endpoint: string): void {
    console.log(method + " " + endpoint + " → 200 OK");
}

sendRequest(HTTPMethod.GET, "/api/users");
sendRequest(HTTPMethod.POST, "/api/users");
sendRequest(HTTPMethod.DELETE, "/api/users/1");
